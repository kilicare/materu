# MATERU Brand Kit v1.0

This is the production-ready starter package for the MATERU brand direction shown in the supplied reference board.

## Core identity
MATERU — DIGITAL PRODUCTS
Palette: Materu Ink #0B0C0E / Warm Ivory #F3F1EB / Signal Orange #FF5A36
Primary typeface: Manrope
Descriptor: DIGITAL PRODUCTS

## Folder map
01_LOGO       Logo masters, exports, lockups and usage sheet
02_FAVICON    Favicon/app icon exports
03_COLORS     Swatches, CSS and JSON tokens
04_TYPOGRAPHY Typography guidance
05_DESIGN_SYSTEM UI tokens and CSS
06_SOCIAL     Social post/story templates
07_WEBSITE    Web logos, favicon, OG image and metadata
08_BRAND_GUIDELINES PDF + Markdown brand guide
09_MOCKUPS    Presentation mockups
10_SOURCE     Reference board, SVG source and documentation

## Important production note
The supplied board is a visual reference. The SVG master marks in this package are a clean vector reconstruction of the visible direction, not the original designer's proprietary source file. Before a legal/trademark filing or mass production, the final mark should be checked against the intended approved master.

## Recommended next step
If an original vector master becomes available (AI/EPS/Figma/SVG from the designer), replace the reconstructed SVG files while preserving this folder structure and export system.
